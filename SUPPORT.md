## Ask a question

Use [GitHub Discussions -> Q&A](https://github.com/MojolaoluwaOlanusi/Tudu/discussions).

Include:

* What you tried

* What happened

* What you expected

* Your environment (OS, Node version, browser, hosted or self-hosted)

## Something is broken

Open an issue with the Bug report template:

<https://github.com/MojolaoluwaOlanusi/Tudu/issues/new/choose>

Include reproduction steps and, if possible, screenshots or a short GIF.
Bugs affecting auth, billing, or data integrity get triaged first.

## Feature request

Open an issue with the Feature request template, or start a Discussion
under "Ideas". Check [FUTURE_WORK](readme/FUTURE_WORK.md) first - the idea may already
be planned with notes.

## Security

Do not open a public issue. See SECURITY.md.

## Account and billing

Email <olanusimojola@gmail.com> with the email address on your account.
Do not include card details - payments are handled by Paystack and never
touch this repo.

## Self-hosting support policy

Self-hosted installs are supported on a best-effort basis. Issues are
triaged and answered in the same queue as hosted issues, but paid hosting
customers get priority. If you need a guaranteed response time, contact
us about the Enterprise plan.

## Documentation request

If a doc is missing or wrong, use the Docs request template or open a
PR. Documentation improvements are the easiest way to contribute.
